PIPELINE DATA FLOW

INGEST → Playwright bots watch DBE press releases + NSFAS circulars page (24h cron)
↓
CLASSIFY → scikit-learn TF-IDF: MatricReport | APSBooklet | NSFASPolicy | LabourData
↓
EXTRACT → pdfplumber (tables) · PyMuPDF (prose) · Tesseract (scanned legacy docs)
↓
VALIDATE → Pydantic models flag missing fields (e.g. missing APS score)
↓
STORE → Flat JSON/CSV committed to enil-data (private)
↓
PUBLISH → GitHub Actions copies validated data to enil-site → Pages auto-deploys

Publishing plain-language appeal grounds by rejection code — something NSFAS itself does not do clearly — is ENIL's single highest-value content asset. Success rate with correct grounds: ~43%.
