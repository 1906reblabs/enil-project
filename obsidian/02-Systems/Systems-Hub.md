### Manual Pipeline Commands

```bash
# Full pipeline run
python pipeline/pipeline.py --source all

# Single source
python pipeline/pipeline.py --source nsfas
python pipeline/pipeline.py --source dbe
python pipeline/pipeline.py --source aps
python pipeline/pipeline.py --source labour

# Dry run (validate only, no writes)
python pipeline/pipeline.py --dry-run

# Weekly orchestration (full Monday run)
python weekly_orchestrator.py

# Single phase
python weekly_orchestrator.py --phase 1   # intelligence only
python weekly_orchestrator.py --phase 3   # revenue only
python weekly_orchestrator.py --phase 4   # optimisation only
```

### Dataview Queries (add to dashboard notes)

```dataview
// All open revenue prospects
TABLE type, stage, value_r, next_follow_up
FROM "06-Prospects"
WHERE stage != "won" AND stage != "lost"
SORT value_r DESC
```

```dataview
// All weekly logs this year
TABLE week, opportunities_found, total_effort_h
FROM "04-Weekly-Logs"
WHERE type = "weekly-intelligence-report"
SORT date DESC
LIMIT 12
```
