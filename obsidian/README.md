# ENIL Obsidian Vault — Setup Guide

This vault is the operating brain of ENIL. It connects your weekly intelligence reports,
revenue pipeline, content calendar, and system health into one navigable knowledge system.

---

## Quick Setup (10 minutes)

### 1. Open this folder in Obsidian

1. Download Obsidian from [obsidian.md](https://obsidian.md) (free)
2. Open Obsidian → "Open folder as vault"
3. Navigate to your `enil-data/obsidian/` folder → Open

### 2. Install Essential Plugins

Open Settings → Community Plugins → Browse → search and install:

| Plugin | Why You Need It |
|--------|----------------|
| **Templater** | Auto-populates dates in templates when you create new notes |
| **Dataview** | Lets you query notes like a database (revenue pipeline table, etc.) |
| **Calendar** | Weekly log navigation in the sidebar |

After installing, enable each plugin.

### 3. Configure Templater

Settings → Templater:
- Template folder: `templates`
- Enable "Trigger Templater on new file creation"
- Enable "Automatic jump to cursor"

### 4. Your Home Note

Open `00-MOC/ENIL-MOC.md` — this is your command centre.
Pin it (right-click tab → Pin) so it's always visible.

## Weekly Workflow

### Every Monday Morning

**Step 1:** Run the orchestrator
```bash
cd enil-data
python weekly_orchestrator.py
```

**Step 2:** Open the new weekly log
- It auto-generates in `04-Weekly-Logs/YYYY-WNN.md`
- Or open the template: Cmd/Ctrl+P → "Templater: Create new note from template" → `weekly-log-template`

**Step 3:** Work the queue
- Check for 🔴 URGENT items first
- Work through 📅 THIS WEEK tasks
- Update revenue pipeline in `06-Prospects/` after any contact

**Step 4:** Update moat scores in `00-MOC/ENIL-MOC.md`
- Data Moat: based on data freshness + cross-reference capability
- Distribution Moat: count newsletter subscribers + WhatsApp members
- Trust Moat: qualitative assessment of community citations
- SEO Moat: based on Google Search Console impressions

## Dataview Queries

Add these to any note for live dashboard views:

**Open Revenue Prospects:**
```dataview
TABLE org_type as Type, stage as Stage, value_r as "Value (R)", next_follow_up as "Follow-up"
FROM "06-Prospects"
WHERE type = "prospect" AND stage != "won" AND stage != "lost"
SORT value_r DESC
```

**Recent Weekly Logs:**
```dataview
TABLE opportunities_found as Opportunities, total_effort_h as "Effort (h)"
FROM "04-Weekly-Logs"
WHERE type = "weekly-intelligence-report"
SORT date DESC
LIMIT 8
```

**Published Content:**
```dataview
TABLE status as Status, date as Date
FROM "05-Content"
WHERE type = "newsletter"
SORT date DESC
```

## Key Principles

1. **The vault serves the system, not the other way around.** If updating a note takes more than 2 minutes, simplify it.

2. **Weekly logs are auto-generated.** Don't try to fill them manually — run the orchestrator, paste its output, add your notes.

3. **Revenue notes move through stages.** When you contact a prospect, change their `stage:` field. This keeps the Dataview pipeline accurate.

4. **The moat dashboard is the north star.** Update it every Monday. If a moat score hasn't moved in a month, ask why.

5. **Intelligence drives content, not the other way around.** What NSFAS is doing this week determines what ENIL publishes — not the content calendar.

## Sync to enil-data Repository

The `obsidian/` folder lives inside `enil-data/`. The weekly orchestrator automatically copies new weekly logs to it. To keep the vault synced:

```bash
# From enil-data root:
git add obsidian/
git commit -m "📓 Vault update $(date +%Y-%m-%d)"
git push
```

Or use the **Obsidian Git** plugin for automatic commits on a schedule.
